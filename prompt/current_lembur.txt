HARI KERJA (HARI MASUK KERJA DAN TIDAK LIBUR) :
Dibagi menjadi : 
    1. Hari Kerja Jam Panjang (Senin,selasa, rabu, kamis, sabtu)   
    2. Hari Kerja Jam Pendek (Jumat)

HARI LIBUR / RESTDAY / OFFDAY : 
Dibagi menjadi : 
    1. Minggu
    2. Public Holiday Non Keagamaan
    3. Public Holiday Keagamaan


#rule perhitungan jam lembur  :
   1. Pada hari kerja jam panjang lembur dihitung jika jam kerja nya melewati lebih dari 7 jam,
   2. Pada hari kerja jam pendek lembur dihitung jika jam kerja nya melewati lebih dari 5 jam, 
   3. Pada hari libur, lembur dihitung dari jam awal  jadi tidak perlu melewati batas minimal jam, 

(kan dari database sudah ada hours atau jumlah jam nya, sehigga bisa langsung menggunakan jam lembur itu tanpa perlu menghitung)

PERHIUTNGAN DIISNI  NANTI SEPERTI Ini, 
disini perhitungannya bertingkat, jadi ada jam pertama, kedua, dan ketiga,
misal jam lembur 3 jam = UPJ X rate_jam_lembur_2 (x1) + UPJ X rate_jam_lembur_3 (x2)
misal jam lembur 5 jam = UPJ X rate_jam_lembur_1  (x1) + UPJ X rate_jam_lembur_2 (x1) + UPJ X rate_jam_lembur_3 (x3)


berikut sebaran rate lembur berdasarkan hari nya : 

1. Hari Kerja Jam Panjang dan Pendek  : 
    1.1 Jam Pertama : 1.5x
    2. Jam Kedua : 2x

    contohnya :
     misal kam lembur 5 jam = UPJ X 1.5 (x1) + UPJ X 2 (x4)
    
2  OFF DAY (Hari minggu)  dan Libur  (Public Holiday Non Keagamaan ): 
    2.1 Jam Pertama  (Pada hari Jumat (jam pendek) maka batas jam pertama 0-5 Jam, sebaliknya jika lembur di hari kerja jam panjang (hari libur)  atau hari minggu  maka batas jam pertama 0-7 Jam): 2x
    2.2 Jam Kedua : 3x
    2.3 Jam Ketiga : 4x

    contohnya :
     misal kam lembur 6 jam (libur di hari jam panjang atau hari minggu) = UPJ x 2 x (x6)
     misal kan lembur 10 jam (di hari libur hari jam pendek) = UPJ x 2 x (x5) + UPJ x 3 x (x5)
     

3 Public Holiday (Libur Keagamaan) : 
    3.1 Jam Pertama (Pada hari Jumat (j`am pendek) maka batas jam pertama 0-5 Jam, sebaliknya jika lembur di hari kerja jam panjang (hari libur)  atau hari minggu  maka batas jam pertama 0-7 Jam): 3x
    3.2 Jam Kedua : 4x
    3.3 Jam Ketiga : 4x

    contohnya :
     misal jam lembur 6 jam (libur keagamaan di hari jam panjang atau hari minggu) = UPJ x 3 (x6)
     misal jam lembur 8 jam (libur keagamaan di hari jam panjang atau hari minggu) = UPJ x 3 (x7) + UPJ x 4 (x1)
     misal jam lembur 6 jam (libur keagamaan di hari jam pendek) = UPJ x 3 (x5) + UPJ x 4 (x1)
     misal jam lembur 10 jam (libur keagamaan di hari jam pendek) = UPJ x 3 (x5) + UPJ x 4 (x5)
