## Qwen Added Memories
- Division definitions for PT Rebinmas: PG = Parit Gunung (NOT Plantation Group), AR = Air Ruak (NOT Arbei). Real divisions from database (extend_db_ptrj.Divisi_Description): P1A=Parit Gunung 1A, P1B=Parit Gunung 1B, P2A=Parit Gunung 2A, P2B=Parit Gunung 2B, DME=KEBUN DME, ARA=KEBUN ARA, AB1=Air Ruak B1, AB2=Air Ruak B2, ARC=Air Ruak RC, IJL=KEBUN IJL, INF=INFRASTRUKTUR, NRS=NURSERY, MILL=MILL PKS, PGE=Parit Gunung Estate, WKS=WORKSHOP. Virtual divisions: WKS_PG=WORKSHOP PARIT GUNUNG, WKS_AR=WORKSHOP AIR RUAK. Gang prefixes: P1A→A, P1B→B, P2A→C, P2B→D, DME→E, ARA→F, AB1→G, AB2→H, INF→I, AREC→J, IJL→L, STF-OFFICE→O, SECURITY→SEC. Aliases: INFRA→INF, NURSERY→NRS, PG1A→P1A, PG1B→P1B, PG2A→P2A, PG2B→P2B. Source: extend_db_ptrj database table Divisi_Description and backend/data/area_produktif.json.
- Tunjangan Beras source: Table HR_PAYROLL, column RiceRation (beras_rate). Formula: beras_jumlah = beras_rate × jumlah_hk. Query: SELECT RiceRation FROM HR_PAYROLL WHERE EmpCode = ?. Beras rate also maps to PTKP status for tax calculation. File references: backend/query/Tunjangan/Payrate_Beras.sql, backend/src/services/payroll/components/TunjanganService.ts
